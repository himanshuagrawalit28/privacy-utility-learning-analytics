# Privacy-Utility Learning Analytics (PrivaLearn AI)

A machine learning framework and analytical platform investigating privacy-utility tradeoffs in educational analytics using **Differential Privacy (DP-SGD)** and evaluating resilience against **Membership Inference Attacks (MIA)**.

---

## Repository Structure

```tree
privacy-utility-learning-analytics/
├── frontend/                 # React 19 + Vite web application
│   ├── src/                  # Application source code & UI components
│   ├── public/               # Static assets & icons
│   ├── scripts/              # Automated verification test suites
│   ├── package.json          # Frontend dependencies & scripts
│   ├── vite.config.js        # Vite build configuration
│   ├── tailwind.config.js    # Tailwind CSS design system
│   └── README.md             # Detailed frontend documentation
└── README.md                 # Project root documentation
```

---

## Getting Started with Frontend

Navigate into the `frontend` directory:

```bash
cd frontend
npm install
npm run dev
```

For comprehensive documentation on the frontend application architecture, features, routes, and differential privacy benchmarks, refer to the [Frontend README](frontend/README.md).
